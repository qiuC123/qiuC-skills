# 故事视频制作

从现有材料和本次交付目标接着做，只加载当前需要的能力。已经完成的简报、字幕解析、核片记录和工程可以复用；不要求每次从选题开始，也不把一个单阶段请求扩成完整制作。

## 选择路径

- **电影、动画剧集解说＋原片**：读取 [references/film-commentary-workflow.md](references/film-commentary-workflow.md)，组织字幕梳理、候选片段、逐源核查、回改文案和制作。
- **漫画解说＋图格展示**：读取 [references/manga-commentary-workflow.md](references/manga-commentary-workflow.md)，核对版本、卷章页格与阅读顺序，再安排旁白、图格停留和必要移动。
- **混合来源**：只读取涉及的分支。各来源分别定位和核查；同一作品的漫画、动画与电影不能拼成一个版本已发生的事实。
- **纯故事文案**：交给 `story-video-writer`，按用户范围交付；素材不完整仍可写有依据的草稿，不能虚构画面、原声或已验证的制作位置。
- **其他视频**：按下表选择能力，沿用用户的画幅、平台和素材，不套用影视模式的默认值。
- **公众号图文**：使用 `story-wechat-producer`；与视频共用事实材料，分别组织文字和视觉内容。

## 能力路由

先检查当前环境实际提供的技能、连接器和本地工具。表中的名称是可选入口，不表示已经安装，也不构成自动安装、升级或付费授权。

| 当前工作 | 优先选择 | 交付或完成条件 |
| --- | --- | --- |
| 故事旁白、片段/图格选择意图、核查后的改稿 | `story-video-writer` | 配音稿及对应原片或漫画图格安排；纯口播只交所需正文 |
| 其他选题、脚本、分镜 | 已有写作/策划能力；`prompt-engineer` 仅在需要设计提示词时使用 | 与当前目标相符的简报或脚本，不强制完整策划表 |
| 本地字幕、媒体信息、抽帧、片段与音频检查 | 已安装的媒体能力，如 `media-use`；或本地 FFmpeg/ffprobe 等工具 | 带来源和实际核查状态的材料，区分提取成功与内容已检查 |
| 漫画文件、页图和文字核对 | 当前可用的图片/PDF 阅读、渲染、裁切与 OCR 能力 | 原页到图格的可追溯定位；OCR 结果须对原页核实 |
| 旁白配音、字幕、声音与片段编排 | 现有媒体工具和已有剪辑工程 | 可继续编辑的素材或时间线；按实际声音校准时长 |
| HTML 视频、动画和图形包装 | `hyperframes` 及其实际可用的 CLI/动画能力 | 按工程约定检查并预览；需要成片时再渲染 |
| 外部剧情依据、访谈或平台内容 | 匹配来源的专用连接器/skill；需要其平台后端时使用 `agent-reach`；否则用可用的搜索与读取工具 | 可追溯且与当前疑点有关的资料 |
| 内容或成片检查 | 写作与媒体能力；有具体事实/权利/宣传问题时可用 `reality-checker` | 修正实际问题，说明尚未核实的项目 |

调用前读取所选 skill。缺少某项能力时先用现有工具完成能做的部分；必要依赖确实缺失时再说明具体缺口。不安装整套可选 Agent，不把没有执行的检查写成已通过。

## 连续执行与交接

1. 沿用平台、受众、来源类型、版本、讲述范围、时长、现有材料和授权。剧集记录季/集/特别篇边界；漫画记录卷/章边界；局部讲述不自行扩为全作。只有缺失信息会实质改变交付时才询问；拿不到用户电脑上的路径时如实说明，提供能由本地执行的交接。
2. 按当前证据和产出接续：只有字幕或 OCR 文本先整理并提出候选；有原片/漫画页先核查关键疑点；有初稿先校正再改稿；有工程继续该工程。不要求在不同应用之间来回传递，也不要求每个阶段重新批准。
3. 只在需要外部内容时调研。发布目标写“抖音/B站”、材料里出现网址或人物提到某网站，不自动触发外网搜索；已上传的字幕和原片直接本地处理。
4. 先用已核实的源素材与有效脚本建立试排，再以实际声音和必要画面阅读时间调整。内容、切点或图格顺序有变化时，同步修改旁白、字幕和时间线，不能仅把旧稿润色得更顺。
5. 复用现有制作方式。普通电影片段拼接不强制转成 HyperFrames；需要 HTML 图形包装时再接入，先读取项目 `AGENTS.md` 和所用能力的要求。
6. 交付用户要求的阶段成果，并说明哪些是候选、哪些已实测。成片需要看实际输出并检查声音和关键衔接；文字校对、文件导出或命令成功都不能替代成片检查。

## 操作边界

- 在用户已授权的范围内连续工作。按现有明确授权处理安装、服务调用或上传；缺少授权时不自动登录、读取 Cookie、持久安装/升级工具、发生费用或发布。
- 本地路径和原始素材按用户指定处理，保留源文件。向外部服务上传影片、音频或其他素材前确认授权是否覆盖该服务和用途，不能默默切换到另一家服务。
- 不把规划好的片段称为已剪辑，不把字幕/OCR 候选称为已看过素材；漫画新增配音标明角色演绎，不称作原声。不以固定素材秒数/比例保证平台审核、授权或流量。
- 版本检查仅在用户要求或具体兼容问题需要时进行。使用当前安装版本支持的查询方式，不在任务收尾固定执行 `npx ...@latest` 或自动升级。
