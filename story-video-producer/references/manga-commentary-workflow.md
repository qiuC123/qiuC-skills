# 漫画图格与视频制作流程

用于漫画故事的“旁白＋图格展示”视频及局部制作。文字交给 `story-video-writer`；本分支负责原页证据、阅读顺序和实际展示。只在同时使用影片时读取影视分支，不把漫画页当作等待提取的电影帧。

## 输入、范围与构图

- 沿用用户已有稿件、漫画版本、卷章范围、平台、时长和工程。默认讲给没看过作品的人听，讲清约定范围内的故事；不能自动用后续章节、动画改编或其他译本填补空白。
- 先识别手头是原页图片、扫描 PDF、漫画压缩包、条漫长图还是只有 OCR 文本。检查当前能否实际读取；未知格式先确认内容，不凭扩展名假设页码和阅读方向。
- 有原页就先核查关键页格；只有 OCR/梗概仍可写有依据的草稿及候选展示意图，但气泡归属、表情、动作和页格顺序保留待核。缺页处不能靠剧情常识补齐。
- 漫画没有电影原声。新增角色配音属于角色演绎，音乐与音效属于制作添加；若采用动画改编声音，单独标明影视来源，不能称为漫画原声或据此断定漫画人物语气。
- 按用户指定画幅制作。未指定时，根据原页比例、图格形状和手机阅读需要选择构图；不直接套用影视分支的横屏默认，也不擅自强裁原页。已有工程只做当前需要的调整。

## 1. 建立可查找的原页位置

不同版本和文件记录稳定的 `source_id`，来源类型为 `manga`，并记录版本及卷/章信息。建立简短页码对应：文件页序、原书印刷页码（如果有）、图片文件名；封面、空白页和双页跨页会导致页码不一致，不能把 PDF 第 12 页直接说成书中第 12 页。

为使用到的页格记录 `reading_order`：按该版本实际阅读方向和气泡衔接判断，不默认所有漫画都是右到左。格号可在记录中自行编号，但说明编号按何种顺序；不要冒充原作自带的编号。双页跨页保留左右关系。条漫没有稳定纸面页码时，用章节、图文件及可复查的纵向区域/格序定位。

OCR 用来检索和辅助转录；必须回看原页核对人名、否定词、标点、气泡归属和阅读顺序。气泡对白、叙述框、人物心声与拟声词分别理解。不要把旁白框归给画面中的角色，也不要将同页相邻气泡强行写成互相回应。

## 2. 让旁白与图格共同讲述

先梳理目标、行动和后果，再安排展示。旁白交代省略的过程、必要背景与因果；图格呈现关键动作、关系、发现或情绪。重要对白可让观众阅读，也可用标明的角色演绎呈现；不在展示前就把整句信息讲完，又让观众重复读一遍。

图格承载关键信息时，要在手机上读得清，并按文字量留足时间。无法同时听旁白并读完复杂对白时，缩减旁白、分步展示或明确由旁白转述；不能让读气泡成为理解故事的隐性考试。

画面移动用于引导阅读或展示原页中的局部信息。适度裁切、推拉和停留不能删掉改变对白含义的对象、反应或前后格。不要把新增的运动、音效或对白表演当作原作已画出的连续动作。

## 3. 核对原页并回改文案

优先检查会改变因果、说话人、情绪判断、跨格动作或转折的页格。查看必要的前后页与完整跨页，再决定使用哪些局部。静态图格可证明可见内容，跨格运动和省略时间仍需依据画面关系判断；分镜解读用自然的解释语气，不能直接说成作者确认的意图。

使用当前可用的图片/PDF 工具查看原页，按需提取或裁切到独立输出目录，保留源文件。区分文件已提取、页图已查看、文字已校对与阅读顺序已核对。提取、OCR 或渲染成功都不等于完成内容核查。

原页不支持初稿时，调整判断、因果、段落顺序或候选图格；不能只润色句子后找一张相似画面配上。资料来自原作访谈、其他版本或现实理论时标清来源，不能补成当前漫画已经画出的情节。

## 4. 轻量记录与交接

沿用现有工程格式或 Markdown 表，不强制建立 JSON 项目。只记录本次需要的素材：

| 记录 | 内容 |
| --- | --- |
| 标识与文字关联 | 稳定图格 ID；对应旁白段落或独立阅读位置 |
| 来源与定位 | `source_id`、版本、卷/章；文件页与印刷页的对应、页内格序；条漫可用图片与纵向区域 |
| 阅读与核查 | 阅读方向、前后格关系；页图已查看、文字与气泡归属已校对等实际状态 |
| 展示意图 | 要呈现的信息，整页/跨页/局部的选择，必要停留或移动；候选状态与待核问题 |
| 时间线 | 成片展示起止、实际声音和展示时长；没有试排时标估算 |

页格位置是原作定位，成片时间是制作编排，两者不能混用；没有源视频就不编造源时间码。裁切导出文件保留原页和裁切区域的映射。混合漫画与影片时，分别保留卷章页格和季集/源时间定位。

跨会话交接提供稿件、素材记录、版本/范围、原页或可访问路径、事实修正与本次目标。不能假定另一台机器能访问当前绝对路径；仅有文字时说明尚未实看哪些页格，不阻止有依据的初稿继续推进。

## 5. 配音、试排与成片检查

只要文案就交干净的旁白正文及图格安排，制作指令不放进配音正文。完整制作则按已有授权继续，用实际配音长度与必要阅读时间试排；旁白粗估可暂用每分钟 220—280 个中文字，实际录音取代估算。阅读停留、角色演绎及旁白重叠按真实时间线计算一次。

复用已有编辑工具与工程；需要 HTML 动画或图形说明时再接入 HyperFrames。角色演绎、配乐或音效按用户声音方案制作，不因漫画缺乏原声就自动新增整套配音。时长过长先删重复、调整详略与展示方式，不用持续加速、强行略去关键格或未经同意拆系列来硬凑。

检查实际导出的画面和声音：小屏中文字是否可读、阅读顺序是否明确、跨页有无错位、移动是否遮挡气泡或跳过关键格、裁切是否改了意思、旁白与图格是否同步，以及音量、截断话语、黑帧和转场。静止展示本就是漫画视频的一种选择，不能把所有停留当成冻结故障。

修正发现的问题后复查受影响部分。仅验证文件、草稿或导出命令时，不能宣称已经完成成片视听检查；缺少原页或关键事实时可交有标记的草稿/试排，不能称为可发布终稿。外部服务、上传、费用和发布沿用入口中的具体授权规则。
