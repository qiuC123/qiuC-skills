# 配音稿与素材编排表

只在混合解说、素材定位或时长交接需要时使用。影视采用原片插入表，漫画采用页格展示表；按所用素材读取对应部分。本文件规定交付关系，不要求执行剪辑。

## 干净的配音稿

按实际需要录制的旁白顺序分段，正文只包含要念的话。不混入段号、时间码、“播放原片”、停顿指令或画面说明。展示时可用正文外的标签区分两个交付部分。

在插入表中用“配音稿第 1 段”等位置关联旁白，段号不进入口播正文。已有工程使用稳定 ID 时沿用，改写后更新映射；不要让配音工具根据制作标记猜哪些内容该读。

## 影视原片插入表

按成片顺序排列，包含必要的旁白锚点及原片段。只保留本稿有用的字段，不为简单片段制造一张难读的大表。

| 字段 | 用途 |
| --- | --- |
| 段落标识／顺序 | 稳定识别本段，说明在成片中的先后 |
| 类型与旁白关联 | 解说、原片或衔接；关联配音稿哪一段，原片独占段可无旁白 |
| 原片依据与定位 | source_id、文件／版本，剧集注明季/集；已核实入点和出点，或候选场景与查找线索 |
| 保留内容与作用 | 保留哪句对白、哪段动作或反应，为什么需要它 |
| 声音／字幕衔接 | 谁主导声音，旁白何时退出或接回，字幕是否有重复遮挡风险 |
| 时长与状态 | 实测、按试读估算、候选或待定位；需要时再给成片时间区间 |

旁白覆盖原片画面的段落，也要说明画面与所讲事件如何对应。来源相同的相邻段可以合并，不强求逐镜头表。

## 时间与来源

原片入点、出点属于指定源文件；成片位置属于重新编排后的时间线，两者分列。不同版本、片头长度或字幕偏移会改变原片定位，不能直接互换。多集各自记录源文件与同步状态，不能把第 2 集的 00:10:00 当作第 1 集续接时间。

只有字幕时，可以列“字幕候选时间”，同时注明尚未核对画面、说话人和切点。原片片段的起止要考虑完整对白、动作及反应，不能把字幕显示范围直接当作最终剪辑范围。

没有来源定位时填写“待定位：某场景／动作前后”等可检索线索，不编造时间码。未核实的对白用意图或内容概述表示，不加引号冒充原句。未完成原片验证的插入表属于剪辑规划草案。

先按内容选择片段，再核算时长；不要先规定每段只能保留几秒。可保留主候选与替代候选，但只把选定方案计入预算。

## 漫画页格展示表

按成片顺序记录，复用现有稳定 ID，不强制逐格拆表。相邻图格共同表达一个动作时可作为一组，但保留其阅读关系。

| 字段 | 用途 |
| --- | --- |
| 标识与旁白关联 | 对应配音稿段落，或独立阅读停留；新增角色演绎另列文本和角色 |
| 原作定位 | source_id、版本、卷/话/章；文件页与印刷页分开；页内格序或条漫图文件/纵向区域，未知项标待核 |
| 展示与作用 | 整页/一组图格/局部，哪条信息或情绪需要看见，是否涉及跨页揭晓 |
| 文字与声音 | 气泡归属、对白/独白/叙述文字；旁白转述、观众阅读或新增角色演绎；拟声字不当成已有音频 |
| 阅读与衔接 | 已核实的阅读顺序、需要保留的上下格关系、字幕是否挡字；裁切/推拉仅为制作意图 |
| 时长与核查状态 | 成片展示时长的估算或试排结果；页图是否实看、OCR是否对页校正、哪些问题未核实 |

漫画源位置没有秒数；需要成片时间时另列，不把页码换算成伪造的原作时间码。只有 OCR/剧情梗概时可以给场景候选，但不能填写未见过的表情、构图、准确格号或镜头运动。

漫画底图与旁白同步展示的时间不另加；独立阅读停留和独占角色演绎才按实际编排另计。新增声音需标明制作来源，不能填为“漫画原声”。用户要求纯口播时不强制补页格表。

## 声音和观看衔接

- 解说段保证旁白清楚；原片对白与旁白竞争时，说明降低哪一路或调整切点，不硬叠两套完整讲话。
- 原片段通常退出旁白，让关键声音和反应完整。原声可以提前进入或延续到下一画面，但必须保持说话人、时空和语义清楚。
- 原片若已有硬字幕，指出新增字幕可能重叠的位置；不要假定能无损去除。旁白字幕与原对白字幕应对应当时实际发声的内容。
- 在制作交接中注明兼顾竖屏浏览和全屏观看时的人物识别与字幕可读性；实际画幅、排版和安全区由制作阶段核验。不把播放器留白默认做进成片。
- 不指定固定音量参数、响度标准或保证全屏入口出现；这些需要实际素材、播放检查或发布渠道依据。

## 时长预算示例

假设已经试读的旁白为 45 秒，选定的原片独占段为 10 秒，另有 3 秒未被覆盖的停顿，则初排约 58 秒。旁白下方已经同步播放的电影画面不再额外加时；跨段重叠也只计一次。这是虚构计算示例，不是固定模板或平台要求。

只有估算时，说明用到的语速、尚待定位的原片段和需要试读校准的部分。不能声称文案已精确匹配最终成片。

## 虚构写作示例

以下不对应真实作品，没有真实台词或时间码。练习素材：少年平时催队友快走；这次队友受伤，少年说“不想等你”，却停下脚步。

配音稿可写：

> 这一路，少年一直嫌队友走得慢。可这一次，队友受了伤，跟不上了。

原片规划：保留少年说“不想等你”以及停步的动作和必要反应，旁白退出；具体切点待素材定位。那句练习台词不再重复写入配音稿。

若需要接入人物理解，可以写：

> 平时总催别人快走的人，这次自己停了下来。把前后放在一起，两个人的关系就有了变化。

也可以直接接下一件已知事件。不要为了凑齐“解说—原片—点评”三段，编造之后的行动。
